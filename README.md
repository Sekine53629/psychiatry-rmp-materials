# 精神科RMP資材一覧

精神科で使う医薬品の RMP（医薬品リスク管理計画）資材を、販売名ごとに患者向け・医療従事者向けに分けて整理したデータです。
各資材は PMDA に掲載された PDF へ、製品は PMDA の製品ページ（添付文書・RMP）へリンクしています。
患者向け資材には、製薬企業の医療関係者向けサイトからのネット発注の可否・発注サイト・ログイン要否・手順メモを付けています。

- 一覧ページ: https://sekine53629.github.io/psychiatry-rmp-materials/
- データ基準日: 2026-10-23
- 収録: 24 製品、資材 54 件（患者向け 26、医療従事者向け 28）、13 領域。患者向けのうちネット発注可 21 件

## ファイル

| ファイル | 内容 |
|---|---|
| `data/rmp_materials.csv` | 全資材。販売名・一般名・製造販売業者・問い合わせ先（添付文書記載）・資材区分・資材名・資材 PDF・RMP 本体・PMDA 製品ページ・添付文書 PDF・RMP 公表日 |
| `data/rmp_materials_patient_online_order.csv` | 患者向け資材に、ネット発注の可否・発注サイト URL・ログイン要否・発注方法メモを付けたもの |
| `docs/index.html` | 一覧ページ（上の 2 つのデータを埋め込んだ単一 HTML。GitHub Pages で公開） |

CSV は UTF-8（BOM 付き）、改行 LF。Excel でそのまま開けます。

## 出典と注意

- 資材 PDF・RMP 本体・添付文書の URL は PMDA（独立行政法人医薬品医療機器総合機構）の掲載先です。資材が改訂されると URL が変わることがあります。開けないときは PMDA 製品ページから最新の資材一覧をたどってください。
- 問い合わせ先・電話・FAX・受付時間は各製品の添付文書の記載を転記したものです。
- ネット発注の情報は各社の医療関係者向けサイトを 2026-10-23 時点で確認したものです。会員登録の要否や受付条件は変わることがあります。「未確認」はサイトがメンテナンス中などで確認できなかったものです。
- この一覧は薬局・医療機関が資材を取り寄せ、患者に渡すための整理であり、治療上の判断に用いるものではありません。
- 資材そのもの（PDF）の権利は各製造販売業者にあります。このリポジトリには含めていません。
